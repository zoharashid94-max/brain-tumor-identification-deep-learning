# Brain Tumor Identification Based on MRI Images Using Deep Learning

This project focuses on identifying brain tumor grades from MRI images using deep learning and computer vision techniques.

## Models Used

- CNN
- ResNet-50
- MobileNet
- Swin Transformer
- Vision Transformer (ViT)

## Best Performing Model

Vision Transformer (ViT)

## Best Accuracy

99.61%

- Python
- Jupyter Notebook
- Anaconda
- Deep Learning
- Computer Vision
- MRI Image Classification

# Brain Tumor Identification Based on MRI Images Using Deep Learning

An automated deep learning framework engineered for advanced medical image diagnostics. This research project focuses on evaluating and benchmarking multiple state-of-the-art neural network architectures to identify brain tumors accurately from raw MRI datasets.

## 🚀 Key Highlight
* Achieved a stellar peak validation accuracy of **99.61%** by integrating **Vision Transformers (ViT)** with built-in self-attention mechanisms.

## 🛠️ Tech Stack & Frameworks
* **Programming Language:** Python
* **Environment:** Jupyter Notebook
* **Core Architectures Benchmarked:** CNN, ResNet-50, MobileNet, Swin Transformer, and Vision Transformers (ViT).

## 📌 Project Workflow & Methodology
* **Data Preprocessing:** Processed, enhanced, and augmented raw brain MRI datasets to improve generalize performance and prevent overfitting.
* **Model Training:** Implemented and trained SOTA deep learning models for classification.
* **Evaluation:** Conducted detailed comparative analysis across models using standard evaluation metrics (Accuracy, Precision, Recall, F1-Score).
